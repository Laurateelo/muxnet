# Android shopping cart: Windows validation branch

This standalone branch contains an Android shopping-cart application and the automation required to verify it on a Windows runner. It contains source code and tests, with no student report or student identification fields. The default branch is a separate project.

The workflow builds with JDK 17 and Gradle 8.9, runs 8 JUnit tests, runs 21 Android device checks, verifies restart persistence, and captures actual Android Studio desktop output. An IDE process launch or screenshot alone is not a claim that IDE sync or Run completed. The actual artifacts and logs must be reviewed.

The workflow is limited to this validation branch and a manually requested run, with a 60-minute timeout and read-only repository permissions. Evidence is retained for 7 days.
